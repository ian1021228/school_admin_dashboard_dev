> **全校班級一鍵派發 · 08:00 晨間出缺席大看板 · 線上行政抽查核章 · 全校廣播**  
> 由高雄市立七賢國中 107 王禹硯 獨立設計開發，專為學校教務處、學務處與系統管理員打造的現代化智慧校園行政中樞。

---

## 📌 系統全景與權限分級 (RBAC)

本管理端分為兩大權限層級：

### 1. 👑 系統管理員 (System Admin)
- **專屬驗證**：支援系統管理員專屬帳密登入與 Google 帳號授權登入（`ianw.solar@gmail.com`），杜絕任何未經授權之存取。
- **學校管理帳號派發**：建立與管理各級學校之租戶代碼、管理員帳號、安全密碼與授權期限。
- **學校管理後台**：系統管理員可切換進入任一授權學校之後台進行學事行政設定與校園管理。

### 2. 🏫 學校管理端 (School Admin)
- **08:00 晨間全校出缺席監控大看板**：學務處即時掌握全校到校率、請假名單（病假/事假/喪假/公假）與各班通報進度，支援一鍵發送催報提醒與匯出晨間公文報表。
- **線上行政抽查核章與評語中樞**：教務處與學務處可線上抽查各班作業繳交進度、聯絡簿親師簽章率與出勤紀錄，並加蓋公信電子行政戳章（圓形/方形防偽戳記）與行政評語。
- **全校廣播與緊急通報中樞**：發布緊急安全防護、防汛天候停課、公衛流感防疫等即時跑馬推播至全校教師端與家長端。
- **全校班級與兩端帳密統一派發中樞**：
  - 統一設定班級代碼、班級名稱、學生總人數與缺號名單。
  - **一鍵全校批量產生器**：秒級建立各年級各班專屬教師端帳密與家長端憑證。
  - **Excel / CSV 批次匯入與匯出**：一鍵匯出全校帳密清冊供開學列印發送，或匯入既有學籍名冊。
  - 雲端自動同步，導師開學登入即享完整班級，無須手動建班。
